## 核心流程

| 交互方式 | 消息路径 |
|----------|----------|
| **各平台** | Channel → ChannelManager → Bus → AgentLoop |
| **CLI** | 直接 → Bus → AgentLoop |

1. **各平台消息** → Channel → ChannelManager → MessageBus → AgentLoop
2. **CLI 消息** → MessageBus → AgentLoop（不经过 ChannelManager）
3. **AgentLoop** consume_inbound() → 外层循环 → 内层循环（LLM + Tools）
4. **响应** → publish_outbound() → MessageBus → ChannelManager / CLI

## 关键设计

- **双层循环**：外层事件驱动，内层 ReAct 推理
- **全局唯一**：一个 AgentLoop + 一个 MessageBus
- **消息解耦**：Channel 和 Agent 通过 Bus 通信
- **会话隔离**：session_key = channel:chat_id
